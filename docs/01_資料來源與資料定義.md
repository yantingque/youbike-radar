## R1. 即時資料：臺北市 YouBike2.0 即時站點資訊

- **資料集頁面**：<https://data.taipei/dataset/detail?id=c6bc8aed-557d-41d5-bfb1-8da24f78f2fb>（政府資料開放平臺編號 [137993](https://data.gov.tw/dataset/137993)）
- **API 網址**（直接 GET，不需金鑰）：
  ```
  https://tcgbusfs.blob.core.windows.net/dotapp/youbike/v2/youbike_immediate.json
  ```
- **格式**：JSON 陣列，一個元素 = 一個站點
- **更新頻率**：約每分鐘
- **重要限制**：**只有「現在這一刻」的狀態，沒有歷史。** 想做預測就必須自己定時抓下來存（已寫好 `scripts/collect_realtime.py`）。

### 欄位定義

| 欄位 | 中文意義 | 型態 | 範例 | 備註 |
|---|---|---|---|---|
| `sno` | 站點代號 | 字串 | `500101001` | 主鍵。前綴 `5001` = 臺北市 |
| `sna` | 站點名稱 | 字串 | `YouBike2.0_捷運科技大樓站` | 帶 `YouBike2.0_` 前綴；去掉前綴才能對上歷史資料 |
| `sarea` | 行政區 | 字串 | `大安區` | 12 區＋「臺大公館校區」共 13 類 |
| `ar` | 地址 | 字串 | `復興南路二段235號前` | |
| `snaen` / `sareaen` / `aren` | 英文站名／區名／地址 | 字串 | | 分析用不到 |
| `latitude` / `longitude` | 緯度／經度 | 浮點 | `25.02605` / `121.5436` | 做地圖、算離捷運站距離 |
| `Quantity` | 總車柱數（站點容量） | 整數 | `28` | 5 ~ 99 |
| `available_rent_bikes` | **可借車輛數** | 整數 | `13` | 預測目標候選 |
| `available_return_bikes` | **可還空位數** | 整數 | `15` | 預測目標候選 |
| `act` | 營運狀態 | 字串 | `"1"` | 1 = 營運中，0 = 暫停營運 |
| `mday` | 站點資料最後更新時間 | 字串 | `2026-10-28 15:32:02` | 站點太久沒更新代表可能故障 |
| `infoTime` / `infoDate` | 資料時間／日期 | 字串 | | 通常同 `mday` |
| `srcUpdateTime` / `updateTime` | 平台更新時間 | 字串 | | 整批資料的更新時間 |

### 2026-10-28 15:32 實測快照

- 站點數：**1,823 站**，其中營運中 1,798、暫停 25
- 總車柱：**51,781 柱**
- 可借車 = 0（借不到車）：98 站；可還位 = 0（還不了車）：57 站
- 站點最多的行政區：內湖 229、大安 218、中山 208、士林 158、中正 138
- ⚠️ **資料品質**：有 845 站「可借 + 可還 < 總車柱」，差 1~2 柱最常見。推測是故障或維修中的車柱，計算「滿站率／空站率」時要用 `可借 ÷ (可借 + 可還)`，不要直接除以 `Quantity`。

## R2. 即時資料：新北市 YouBike2.0

- **API**：`https://data.ntpc.gov.tw/api/datasets/010e5b15-3823-4b20-b401-b1cf000550c5/json?page=0&size=1000`（要翻頁）
- 欄位命名跟臺北不同：`tot_quantity`（總柱）、`sbi_quantity`（可借）、`bemp`（空位）、`yb2_quantity` / `eyb_quantity`（一般車／電輔車可借數）、`lat` / `lng`、`mday` 格式為 `20261028T152904`
- 用途：臺北租借紀錄裡有很多「還到新北」的站，要分析跨市流動時才需要。

## R3. 即時資料：交通部 TDX

- **註冊**：<https://tdx.transportdata.tw/>（免費，拿 Client ID / Secret）
- **端點**：
  - 站點基本資料 `GET /api/basic/v2/Bike/Station/City/Taipei`
  - 即時車位 `GET /api/basic/v2/Bike/Availability/City/Taipei`
  - 自行車道路網 `GET /api/basic/v2/Cycling/Shape/City/Taipei`
- **驗證**：OAuth2 client credentials（實測不帶 token 回 401）
- 優點：全台各縣市格式統一；缺點：要申請金鑰、有呼叫次數限制。**本專案以 R1 為主，TDX 當備援。**

## H1. 歷史資料：YouBike2.0 票證刷卡資料（租借紀錄）

- **資料集頁面**：臺北市資料大平臺「YouBike2.0 歷史資料」
- **索引檔**（列出所有月份的下載網址）：
  ```
  https://tcgbusfs.blob.core.windows.net/dotapp/youbike_second_ticket_opendata/YouBikeHis.csv
  ```
  索引檔欄位：`UpdateTime`、`SrcUpdateTime`、`fileinfo`（例：2026年7月）、`fileURL`（zip 下載網址）
- **涵蓋期間**：**2020 年 4 月 ~ 2026 年 7 月，共 76 個月**（約晚 1~2 個月上架）
- **檔案大小**：一個月 zip 約 130 MB，解壓後 CSV 約 **890 MB**（UTF-8）
  → 不要一次全部讀進記憶體，用 pandas `chunksize` 或 DuckDB / Polars 處理

### 欄位定義（以 2026/07 檔為例）

| 欄位 | 中文意義 | 範例 | 備註 |
|---|---|---|---|
| `rent_time` | 借車時間 | `2026-07-17 06:00:00` | ⚠️ **只精確到整點**（實測 759 萬筆分鐘全是 00），隱私處理 |
| `rent_station` | 借車站名 | `龍門廣場` | ⚠️ **只有站名、沒有站點代號**，要用站名對回 R1 的 `sna` |
| `return_time` | 還車時間 | `2026-07-17 07:00:00` | 同樣只到整點 |
| `return_station` | 還車站名 | `臺北遠企購物中心` | 包含新北市站點 |
| `rent` | 騎乘時間長度 | `00:22:35` | 時:分:秒，這欄是精確的 |
| `bike_type` | 車種 | `一般車` / `電輔車` | 2026/07 起有此欄，舊檔可能沒有 |
| `infodate` | 資料日期 | `2026-07-17` | |

### 2026/07 實測統計

- 總筆數：**7,596,992 筆**（一天平均約 25 萬趟）
- 日期：檔案內只有 **30 天**（7 月應有 31 天，缺 1 天 → 清理時要檢查）
- 車種：一般車 6,948,862（91.5%）、電輔車 648,130（8.5%）
- 尖峰：**08 時（59 萬）、17~18 時（64~68 萬）**，明顯通勤雙峰
- 借車站 1,767 個、還車站 3,065 個（還車站多是因為跨市還到新北）
- 原站借還：507,014 筆（6.7%）
- 騎乘時間：中位數 **8.1 分鐘**，75% 在 15 分鐘內，95% 在 39 分鐘內；最大值超過 100 小時 → 要設上限過濾異常值
- 最熱門借車站：捷運公館站(2號出口)、捷運中山國中站、捷運科技大樓站、捷運東門站(5號出口)、捷運圓山站(1號出口) → **前十名全是捷運站**
- 站名對照：1,767 個借車站中 **1,758 個（99.5%）**能直接對上即時資料站名
  - 對不上的有兩種：
    1. 原始檔有亂碼（例如「糖?文化園區」應為「糖廍文化園區」）→ 建人工對照表
    2. 內部站點（蘆洲維修中心、3樓客服中心、濱江第二放置場）→ 直接排除

### 這份資料「能做」與「不能做」

| 能做 | 不能做 |
|---|---|
| 每站每小時借出量、還入量、**淨流量** | 精確到分鐘的分析 |
| 起訖（OD）流動、熱門路線 | 個人／卡號層級分析（已去識別） |
| 騎乘時間分布、一般車 vs 電輔車 | 直接得到「某時刻站上有幾台車」（因為有調度車，借還相減不等於庫存） |

→ 「某時刻站上有幾台車」只能靠 **R1 自己收集**。這是本專案最關鍵的資料限制。

## H3. 天氣資料

- **歷史逐時觀測**：中央氣象署 CODiS 氣候觀測資料查詢 <https://codis.cwa.gov.tw/>，選「臺北」測站（466920），下載逐時氣溫、降雨量
- **即時／預報 API**：中央氣象署開放資料平臺 <https://opendata.cwa.gov.tw/>（要免費註冊拿授權碼，實測不帶授權碼回 401）
- 會用到的欄位：氣溫、降水量、是否下雨（降水量 > 0）

## H4. 假日

- 行政院人事行政總處「中華民國政府行政機關辦公日曆表」（data.gov.tw 搜尋即可），標記國定假日、補班日
